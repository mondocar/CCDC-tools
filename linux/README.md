Tested on `Kali Linux (Debian-based)`. Certain features may not work on other distributions.

Be sure to run scripts with `sudo` since they include checks that need evelated privileges. Without sudo permission certain features and important checks might not work!

The script `car.sh` combines all the scripts into one. Run this script if you want to run every check at once.

Usage: `sudo ./car.sh`
